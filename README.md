# 📬 Flash Mail (Temp Mail)

Un outil de messagerie temporaire ultra-rapide, anonyme et open-source. Générez une adresse email jetable en un clic pour éviter le spam et protéger votre boîte principale.

## 🚀 Fonctionnalités

- **Génération instantanée** : Créez une adresse email temporaire en un clic.
- **Boîte de réception en temps réel** : Les emails arrivent automatiquement (rafraîchissement toutes les 5 secondes).
- **100% Anonyme** : Aucune inscription, aucun log, les emails sont éphémères.
- **Design épuré** : Une interface sombre et minimaliste inspirée des outils de développeurs.
- **Responsive** : Parfait sur mobile et sur ordinateur.

## 🛠️ Stack Technique

- **Frontend** : HTML5, Tailwind CSS (via CDN), Vanilla JavaScript.
- **Backend** : Node.js, Express.
- **API** : [Mail.tm](https://mail.tm) (API gratuite de mail temporaire).
- **Hébergement** : [Render](https://render.com).
